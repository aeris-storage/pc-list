支持两种写法，items 里用商品 id 对应：

{
  "date": "2026-11-16",
  "source": "定时任务 · 官方渠道",
  "items": { "商品id-1": 7288, "商品id-2": 3520 },
  "jd":    { "商品id-1": 6099, "商品id-2": 3288 },
  "meta": {
    "low": { "商品id-1": 4799 },
    "avg": { "商品id-1": 5800 }
  }
}

items 是淘宝/天猫价，jd 是京东价，meta 用来顺手更新「6 个月最低 / 均价」，都可选。

落盘位置：把文件放进这个 HTML 同目录的 prices/ 文件夹即可。
同一天重复导入只更新当天那一条，其他日期原样保留。

没有 JSON 也能救急：点某一行右侧的铅笔图标，直接改「当前价」并勾上「写入今天」，效果一样。

怎么用

三件事：勾已购、收价格、加商品

1. 日常

买过的点最左边的方框，整行会变暗、价格划掉，顶部「已购入」会自动累计，不会和没买的混在一起看错。

名字 / 型号写错了？点行尾的铅笔直接改，点「保存」就写回 配件清单.json 并重建本文件， 刷新、换浏览器都在。顶部「保存到源文件」按钮可以随时手动同步一次。

想给商品起个昵称？比如「主力卡」「待入手」。鼠标移到商品行上，品牌后面会浮出「＋ 昵称」， 点一下直接打开编辑窗，光标就落在昵称框里；已经有昵称的，点那个小标签就能改。编辑窗里也有「昵称」一栏， 添加新商品时同样能填。留空就不显示，清空就是删掉昵称，改完点「保存」一样写回源文件，以后重建不会丢。 顶部搜索框也能直接搜昵称。

顶部按钮显示当前状态：配了云端就写「保存到云端」，没配就写「保存到源文件」。 不管哪种，保存成功会有提示；失败时数据仍暂存在浏览器，不会丢，点一下按钮重试即可。

电脑上如果没配云端，双击桌面的「电脑装机小助手」打开即可，它会顺带把本地服务拉起来， 关掉这个页面，服务几秒后自己退出。配了云端之后就不依赖它了，浏览器直接打开部署好的网址就行。

顶部「一套成机」那张卡片，鼠标移上去右上角会亮出「明细」，点一下展开清单： 每一类挑了哪一件、来自淘宝还是京东、小计多少、合计多少，一目了然；再点一次或按 Esc 收起。

普通类目是备选，没点星时取更便宜的一件，点了星就取点星的那件；机箱风扇不是二选一：正叶和反叶型号不同、风向相反， 两件都会列进明细、都算进合计，表格里也会标上「都要买」。哪些类目要「全部都要」写在 配件清单.json 的 pickAllCats 里，以后加同类目新商品会自动一起计入。

哪个类目不想算进整机？每个类目头上都有一个「计入整机」的勾选，默认全部计入。 取消勾选后，这一类就不参与「一套成机」的金额和明细，整组会变淡，右边改成显示「不计入 · 若买 ¥…」； 表格里照常比价、照常看走势、照常勾已购。展开明细时底部会写明有哪几类没算、若都买另需多少钱。 另外三张卡片（全车合计 / 已购入 / 还能省）仍按全部商品算，真买了也会照实计入已花金额。

机箱分两类，只能选一个。「风道机箱」排在前面，「海景房机箱」紧随其后，两者互斥： 勾了一类，另一类会自动变成不计入，保证一套机器只算一台机箱。想换风格就点另一个的勾选。 互斥关系写在 配件清单.json 的 exclusiveGroups 里。

商品多了不好翻？列表上方那一排是筛选器：点「显卡」只看显卡，点几个就同时看几个， 再点一次取消；右边还能直接搜型号、品牌或昵称。筛选只影响显示，顶部四个合计都不受筛选影响， 刷新页面自动回到「全部」。

想自己定哪件进这套机器？点每行最左边的「☆」，它会变成「★」，这件就是该类目的最优选： 自动排到组内第一行，结算也按它算，哪怕同类里有更便宜的。每个类目只能点一颗，点第二颗会自动取消第一颗； 再点一下取消，组内顺序和结算金额立刻复原。没点星的类目，组内按到手价（淘宝 / 京东取更低 × 数量）由低到高排， 结算取最低的那件。类目之间的顺序保持固定，价值高的放前面，不会跟着价格跳。 「机箱风扇」这类「都要买」的类目不显示星星，仍然两件都算进成机； 取消勾选「计入整机」的类目仍能点星，只是那颗星暂时不影响结算，勾回来就继续作数。

不想要某件商品？点行尾的垃圾桶（编辑窗口左下角也有「删除这件」），确认后立刻写回源文件， 以后重建也不会自己跑回来。删错了点筛选条上的「已删除 N」就能恢复，价格历史一起回来； 这份回收记录只存在本浏览器，清缓存后就没有了。

2. 在手机上用（伪 App）

这个页面已经部署在 GitHub Pages 上。手机 Safari 打开部署好的网址，点分享按钮 → 添加到主屏幕，桌面就会多一个带图标的 App，点开全屏运行。首次打开时到 7. 云端同步填一次密钥，之后这台设备自动记住。

手机上看到的是同一份数据：改价格、加商品、勾已购都会写进你自己的私有仓库， 电脑下次打开会自动拉到。屏幕窄的时候表格会变成卡片：每件商品分三行， 第一行是名字和数量，第二行是淘宝价 / 京东价 / 差价，第三行是历史价、状态和走势； 底部有四个标签，筛选条可以左右滑动。

最大的变化：数据不再依赖电脑。你在外面用手机加商品、改价格，直接存进云端， 电脑合盖、关机都不影响。回到电脑打开页面，自动拉取，手机上改的就在了。
没网的时候：App 仍能打开，看到上次联网的页面快照；这期间的改动会暂存在手机里， 联网后自动传到云端。
两台设备同时改了：以最后保存到云端的为准，另一台下次打开会拉到最新，旧数据不会把新的盖掉。

3. 价格怎么进来

价格走两条路：导入（主要）和手动（补充）。导入：AI 检索一轮官方渠道价（天猫旗舰店 / 京东自营 / 京东品牌旗舰店），生成 prices/日期.json，你在这个页面点 导入价格 → 选那个文件，全部价格就刷新了，而且会按日期追加到历史里，以前的日子一条都不动。

想手动补一天也行：点行尾的铅笔，改「当前价」，勾上「写入今天」。

定时任务每 3 天（早上 9 点）自动生成一份检索清单并提醒你。它不自动改价： 搜到的多是过时快照价，补贴叠完的到手价更是查不到，每一笔都该有人当场核对。 所以流程是「清单 → 你交给 AI 检索 → 确认后导入」，顶部「该导入了」的提醒按上次导入的日期算， 改商品信息、改昵称都不会把它重置。

4. 加新商品

最省事的是把商品截图发给 AI Agent，新商品会进 配件清单.json； 如果本机配了云端，再点一下「上传到云端」，手机就能拉到。
在外面就点底部 ＋ 添加（电脑上是右上角「＋ 添加商品」）自己填， 填完点「保存到云端」，立刻写进你的私有仓库，不用等电脑开机。

两边改动互不覆盖：你在网页改的字段和 AI 更新的价格各算各的，删除过的商品也不会被重建加回来。 价格历史按日期追加的规则不变，现在也一并写回源文件，折线图的数据永久留得住。

5. 淘宝 / 京东怎么比

每行两个价格：「淘宝价」是你购物车里的最终价，「京东价」是同款在京东自营/官方旗舰店的价格。 差价那列直接告诉你谁便宜多少（绿色=京东更便宜，陶土色=淘宝更便宜）。 「一套成机」「还能省」「状态」全部按两个平台里更低的那个来算，所以可以放心交叉平台买； 「一套成机」里标「都要买」的类目，按里面每一件分别取更低价再累加。

京东价空着的时候显示「—」，点一下那个 —就能直接填，不用绕去编辑窗口。

同一件东西在别家店的价格（比如同一个板 U 套装，华硕旗舰店和 AMD 旗舰店都在卖）： 淘宝价下面会用小字再列一行，写成「店名 价格」，比当前价更低的会变绿。这类报价只做参考， 不参与排序、差价和一套成机的结算；想改用那家店，编辑窗里把那个数字填成「淘宝价」就行。 在编辑窗的「别家店报价」里，一行写一家（店名 + 价格），改完点保存即写回源文件。

CPU / 主板套装为什么京东价是「2 件合计」
淘宝卖的是「板 U 套装」一整件，京东不卖这个套装，而是把 CPU 和 主板 当两个单品分开上架， 拿整串套装名去搜自然搜不到。所以这两行的京东价 = 两个单品京东价之和，价格子右边会标「2 件合计」， 鼠标停上去能看到每一件分别是多少、来自哪家店。
点京东价那一格打开编辑窗，可以直接改两个单品价，总价自动算；也可以切成「手动填总额」自己填一个到手价。 每 3 天的价格检索清单里这两个商品也会自动列出两个单品分别去检索，不会再因为「搜不到套装」而留空。

6. 状态怎么判断

  • 史低：当前价 ≤ 近 6 个月官方最低价 → 页面会轻轻标绿
  • 可入：当前价 ≤ 近 6 个月均价（你说的「低于中间值就接受」就是这条）
  • 偏高：高于均价，建议再等等
  • 待核：还没查到可靠的历史价

7. 云端同步

开启后，数据存在你自己的 GitHub 私有仓库里，手机和电脑都从那里读写，电脑合盖也不影响。 页面本身是公开的空壳，不含你的商品数据；只有填了密钥的这台设备能读写你的清单。密钥只存在本浏览器，不会写进页面源码。

尚未配置云端

令牌需勾选仓库的 Contents 读写 权限。首次使用：先在 GitHub 建一个私有仓库， 在本机点「上传到云端」把当前清单传上去；手机端填同样的四项，点「从云端拉取」即可拿到全部数据。 以后每次改动点顶部「保存到云端」即写回，手机在外面也能随时加商品。
